# Support

- **A question or a problem using the extension**: read the [README](README.md) first, then search
  the [issues](https://github.com/Arsslensoft/Kemlock-browser/issues). If it is not there, open a
  new one with the bug report form.
- **A bug**: open an issue with the bug report form. Say the browser, its version and the
  extension's version, and what you did. Do not paste a vault, a password, a code or a sync
  address.
- **An idea**: open an issue with the feature request form.
- **A security problem**: do not open an issue. Report it privately, as [SECURITY.md](SECURITY.md)
  says.
- **The Kemlock app or Kemlock Server**: their repositories are private for now. Ask here, and the
  question will be passed on.

To change the code, see [CONTRIBUTING.md](CONTRIBUTING.md).
